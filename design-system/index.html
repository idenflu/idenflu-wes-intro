01 / PRINCIPLES

덜어내고, 더 분명하게.

하나의 화면에 하나의 메시지를 둡니다. 문장의 크기와 무게, 여백으로 읽는 순서를 만듭니다.

01

메시지가 먼저

짧고 구체적인 문장과 선명한 제목으로 중요한 내용을 전달합니다.

02

여백으로 구분

시각적 구획보다 정렬과 충분한 간격으로 내용을 나눕니다.

03

필요한 곳에 색상

무채색을 기본으로 하고, 색상과 그래픽은 꼭 필요한 곳에만 사용합니다.

02 / COLOR

차분한 바탕, 명확한 강조.

무채색을 기본으로 하고, 브랜드와 상태 색상은 의미가 필요한 곳에만 사용합니다. 각 색상은 역할에 따라 구분합니다.

03 / TYPOGRAPHY

읽는 순서가 보이도록.

기본 / PLATFORM

공통 운영 기능을 표준화합니다.

권한, 감사, 알림, 실시간 상태, 설정과 스케줄링을 하나의 기준으로 관리합니다.

테두리 / OPERATION

작업의 흐름을 관리합니다.

업무 규칙과 작업 상태를 하나의 흐름으로 연결합니다.

배경 / AGENT

설비를 연결합니다.

설비별 연결 방식과 상태를 일관된 기준으로 관리합니다.

Comparison / 비교
BEFORE / 분산된 운영

정보를 따로 확인합니다.

운영자가 여러 시스템의 정보를 직접 모읍니다.

  • 작업과 설비 상태를 각각 확인
  • 알림과 조치 이력을 별도로 취합
AFTER / 연결된 운영

운영 흐름을 함께 봅니다.

작업과 설비 정보를 같은 운영 기준으로 연결합니다.

  • 작업과 설비 상태를 함께 확인
  • 알림과 이력을 한 흐름에서 확인
Steps / 단계
  1. 01

    현장 진단

    운영 흐름과 설비, 기존 시스템의 연동 대상을 확인합니다.

  2. 02

    파일럿 범위 정의

    우선 적용할 구역, 업무와 설비를 정합니다.

  3. 03

    운영 검증

    현장 요구사항과 실제 운영 흐름을 기준으로 확인합니다.

  4. 04

    단계적 확장

    검증된 범위에서 설비와 업무를 점진적으로 확장합니다.
